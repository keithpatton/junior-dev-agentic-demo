# Talk 2 embedded-evidence revision — plan v1

## Communication job

By the end, an early-career developer should be able to use AI for greater engineering reach without surrendering understanding or accountability, because they can recognise and operate a visible loop of intent, challenge, decision, evidence, and memory across both product and system concerns.

## Narrative sequence

1. Establish the personal technology shift and the false-confidence tension.
2. State the thesis: the valuable unit is the loop.
3. Show how a vague request becomes a clearer outcome.
4. Define the human responsibilities and consequential checkpoints.
5. Present one eight-step lifecycle without a framework acronym.
6. Embed proposal, challenge, approval, and proof examples as slide-native repository evidence.
7. Explain delegation and evaluation without showing source code.
8. Show the curated context spine as the memory inherited by the next cycle.
9. Make vertical delivery and horizontal strengthening a two-axis engineering model.
10. Reveal the finished application briefly, then close with five provocations.

## Evidence-slide treatment

- Reuse the deck’s cream background, black editorial type, orange accent, monospace labels, footer, and slide numbering.
- Format each example as a deliberately composed repository page, not a literal editor screenshot.
- Show only one consequential excerpt per slide.
- Add a small path such as `presentation/demo/03-socratic-plan-review.md`.
- Highlight the exact sentence or decision the presenter discusses.

## Two-axis visual

- Vertical axis: outcome → flow → behaviour → feedback; this produces a usable product slice.
- Horizontal axis: privacy → contracts → tests → observability → context; this makes slices trustworthy and sustainable.
- State the failure of either axis alone:
  - vertical without horizontal produces plausible but fragile software;
  - horizontal without vertical produces foundations without a user outcome.
- Place the agentic builder at the intersection, working both axes from the beginning.
