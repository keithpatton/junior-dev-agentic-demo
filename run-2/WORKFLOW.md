# Workflow

For each product loop: state a visible outcome, inspect the relevant boundary, make the smallest coherent change, run durable tests, exercise the complete journey in a browser, update these context documents, then commit and tag the working checkpoint.

Phase tags are the presentation safety net. At the venue, pre-open the local server and final browser tab. If a live loop exceeds its stop condition, use the scope nudge once; if it still wanders, switch to the next phase tag and continue the story.

The privacy loop is done only when an old implementation fails a boundary test, the revised serializer passes, and a browser reload shows ordinary application data retained without the note text.
