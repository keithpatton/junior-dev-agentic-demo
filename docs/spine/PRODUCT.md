# Product

## Audience

Early-career developers and teams experimenting with coding agents across different repositories and model providers.

## Intended outcome

Apply / Forward helps a junior developer decide what to do next across active job applications. The surrounding repository lets another developer inspect and adapt the engineering loop used to shape and prove that product.

## Success looks like

- the finished application is useful and understandable without watching code generation;
- the recorded journey shows how product judgment changed the result;
- the planning framework can be copied into another repository without vendor-specific tooling;
- the context spine tells a new human or agent what matters and where to look;
- claims in the talk are linked to evidence and stated with appropriate caveats;
- the entire 30-minute session leaves at least four minutes for questions.

## Non-goals

- teaching a particular coding agent interface;
- presenting the internal framework from which this kit was abstracted;
- maximising agent autonomy or run duration;
- prescribing multi-agent workflows for trivial tasks;
- arguing that source-code knowledge, algorithms, or debugging are obsolete.
