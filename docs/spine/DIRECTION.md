# Direction

## Current focus

Maintain the simplest useful form of the agentic engineering loop around a small working application, with inspectable decisions, explicit boundaries, executable evidence, and durable context.

## Direction of travel

- from one prompt to an explicit, inspectable lifecycle;
- from passive tracking to a user decision and outcome;
- from whole-object convenience to explicit data boundaries;
- from plausible output to layered evidence;
- from transient chat context to a maintained repository spine;
- from code producer to agentic builder with broader systems leverage.

## Deliberate deferrals

- long-running autonomous agent fleets;
- provider-specific orchestration;
- automatic graph generation or optimisation;
- cost and token accounting;
- issue tracker and deployment integration;
- a complete organisational multi-agent operating model.

These may be valuable later. They are not required to preserve the core portable loop now.
