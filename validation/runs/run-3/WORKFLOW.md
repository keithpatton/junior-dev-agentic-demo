# Workflow

Each loop begins with a product outcome and visible stop condition. Inspect the relevant seams, make the smallest coherent change, run automated checks for durable rules, and exercise the full promise in a browser. Update product, architecture, and invariants from observed behaviour; then commit and tag the phase checkpoint.

For presentation recovery, use the scope nudge once, then switch to the next known-good tag instead of debugging on stage. Pre-open the server and browser during the venue tech check.

Privacy is complete when the old boundary fails a test, the projected boundary passes, and a browser save/reload keeps ordinary application fields while removing the secret note.
