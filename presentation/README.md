# Presentation

This folder contains every artifact whose primary purpose is the JuniorDev Auckland talk.

- `Beyond-the-Prompt-JuniorDev.pptx` — the core 30-minute deck.
- `SPEAKER-GUIDE.md` — timings, cues, transitions, demo links, cut points, and fallbacks.
- `journey/` — the real product prompt, discussion record, plans, approval, implementation review, proof, and remembered learning.
- `planning/` — the talk’s own planning trail; useful as a quiet meta example, not the main story.
- `assets/` — generated illustrations and authentic application screenshots used by the deck.
- `rehearsal/` — historical prepared states retained as fallback evidence.

The application at the repository root is the output. The presentation decomposes the journey that produced it.
