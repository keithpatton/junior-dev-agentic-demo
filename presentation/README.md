# Presentation

This folder contains every artifact whose primary purpose is the JuniorDev Auckland talk.

- `Beyond-the-Prompt-JuniorDev.pptx` — the core 30-minute deck.
- `SPEAKER-GUIDE.md` — timings, cues, transitions, demo links, cut points, and fallbacks.
- `demo/` — presentation-ready samples for the slide → show → return walkthrough; no live agent run required.
- `assets/` — generated illustrations and authentic application screenshots used by the deck.
- `research/` — claim calibration, primary sources, caveats, and reading notes for the presenter.

The application at the repository root is supporting evidence, not the centre of the talk. `demo/` is the only folder opened during the prepared walkthrough. Its planning, challenge, approval, implementation, proof, and context samples show an emerging way of working: humans shape, authorise, evaluate, and curate while agents execute between checkpoints.
