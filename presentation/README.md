# Presentation

This folder contains every artifact whose primary purpose is the JuniorDev Auckland talk.

- `Beyond-the-Prompt-JuniorDev-v9.pptx` — the final 19-slide, 30-minute delivery deck. It moves from false confidence into the three-phase loop, human decision ownership, durable context, and the vertical/horizontal agentic-builder synthesis.
- `SPEAKER-GUIDE.md` — timings, cues, transitions, cut points, and fallbacks.
- `demo/` — the repository-owned source material condensed into the evidence slides and available for questions.
- `assets/` — generated illustrations and authentic application screenshots used by the deck.
- `research/` — claim calibration, primary sources, caveats, and reading notes for the presenter.

Stay in PowerPoint through the prepared story. The application at the repository root is supporting evidence, not the centre of the talk; its optional reveal near the end is the only planned switch. The argument is carried by context: humans shape, challenge, authorise, evaluate, and curate while agents execute between checkpoints.
