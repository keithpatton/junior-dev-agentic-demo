# Prepared evidence walkthrough

This folder is the live demonstration. It contains selected evidence from the real planning and implementation journey, not a simulated agent run.

The walkthrough has four short views:

1. [`01-idea-discussion.md`](01-idea-discussion.md) — the broad idea and the questions that changed its meaning;
2. [`03-socratic-plan-review.md`](03-socratic-plan-review.md) and [`04-approved-plan.md`](04-approved-plan.md) — challenge before execution, followed by a human decision;
3. [`05-build-up.md`](05-build-up.md) and [`06-strengthen-across.md`](06-strengthen-across.md) — one product slice and one cross-cutting system improvement;
4. [`07-proof-and-memory.md`](07-proof-and-memory.md) — layered evidence and the context-spine update.

The application is shown for no more than 20 seconds. Its job is to establish that the loop produced running software; it is not the subject of the talk.

No network or live agent is required. The only command is:

```bash
npm run test:spine
```
