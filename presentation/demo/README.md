# Embedded evidence sources

[`agentic-loop-example.md`](agentic-loop-example.md) is the supporting repository artifact. Slides 8, 10, and 12 turn its intent into representative human/agent and agentic-activity views inside PowerPoint. The file remains available for preparation and questions; it does not need to be opened during the talk.

It is deliberately one small file: enough to keep consequential context and human gates inspectable without turning the workflow into a documentation system.

The older focused samples remain useful supporting material for questions. They are not a verbatim transcript or a complete historical system of record, and they do not need to be opened during the prepared talk.

The deck carries a small repository path on each evidence slide so the audience can see that the context is inspectable without watching the presenter switch applications. Keep these files available only for a question that genuinely benefits from the extra detail.

The optional live application reveal is capped at 20 seconds. No source code, network connection, terminal command, or live agent run is required.
