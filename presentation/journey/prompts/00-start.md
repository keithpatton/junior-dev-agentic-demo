# Prompt 00 — start the product journey

Copy this prompt into the coding-agent task from the repository root:

```text
Build a job application tracker for junior developers.

Do not implement anything yet. Interrogate the idea with me before producing a plan. Ask only questions whose answers could materially change the user outcome, scope, product behaviour, data model, privacy boundaries, architecture, failure modes, or validation approach.

Work conversationally rather than sending a questionnaire. Push back on weak or assumed framing, and help me discover whether “tracking applications” is actually the valuable outcome.

Record the meaningful discussion, assumptions, rejected ideas, and decisions in presentation/journey/SESSION-LOG.md. Preserve short decisive quotes accurately; paraphrase the rest clearly.

When context is sufficient, create presentation/journey/artifacts/00-intake.md and presentation/journey/artifacts/01-plan.md. Then run a separate structured challenge pass against the plan and write presentation/journey/artifacts/02-plan-review.md.

Stop for my explicit approval. Do not write implementation code or implementation documentation before that approval.
```
