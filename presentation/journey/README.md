# Recorded product journey

This directory is the system of record for the talk’s living example.

The product journey is:

1. idea;
2. interrogate;
3. reframe;
4. plan;
5. challenge;
6. approve;
7. build and review;
8. prove and remember.

## Recording rules

- Record the user’s meaningful answers and decisions, not every conversational filler word.
- Preserve short important user quotations verbatim and label paraphrases as summaries.
- Link each decision to the artifact it changed.
- Record unresolved questions and rejected assumptions.
- Never backfill a decision as if it existed earlier.
- Keep planned claims separate from executable or browser evidence.
- Stop before implementation until the approval artifact explicitly authorises it.

## Files

- `SESSION-LOG.md` — chronological discussion and decision index.
- `prompts/` — exact prompts used at each gate.
- `artifacts/` — intake, plan, challenge, approval, implementation review, evidence, and accepted learning.
